cypress-docgen

A custom, open-source Cypress plugin I built and published on GitHub. It solves a common problem for QA teams: test coverage lives inside the codebase, so stakeholders, product managers, and QA partners without repository access usually have no easy way to see what is actually being tested. cypress-docgen reads your Cypress test files and automatically generates readable documentation straight from them, with support for custom formats and Markdown output, so the docs stay in sync with the tests instead of being written and maintained by hand separately. In short: tests that document themselves.

Published as an npm library and open-sourced on GitHub: npmjs.com/package/cypress-docgen · github.com/paulomarian0/cypress-docgen. It was later featured by Cypress.io's official Plugin Select program.
