  • Plugin Select: Cypress.io's official program to feature community plugins. They picked and published a post about my custom plugin, cypress-docgen. The plugin solves a common problem for QA teams: test coverage lives inside the codebase, so stakeholders, product managers, and QA partners without repository access usually have no easy way to see what is actually being tested. cypress-docgen reads your Cypress test files and automatically generates readable documentation straight from them, with support for custom formats and Markdown output, so the docs stay in sync with the tests instead of being written and maintained by hand separately. In short: tests that document themselves. You can read the full announcement in Cypress.io's LinkedIn post.
