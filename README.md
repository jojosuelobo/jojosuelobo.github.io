# jojosuelobo.github.io

Personal resume / portfolio page for Josué Lobo (QA Engineer, Developer & AI Enthusiast).

Plain HTML/CSS, no build step, no framework — inspired by the minimalist structure of
[teodecampos.github.io](https://github.com/teodecampos/teodecampos.github.io).

## View locally

Just open `index.html` in a browser:

```
open index.html
```

## Publish on GitHub Pages

1. Create a GitHub repository named `jojosuelobo.github.io`.
2. Push this folder's contents to the `main` branch.
3. In the repo settings, enable GitHub Pages for the `main` branch (root).
4. The site will be live at `https://jojosuelobo.github.io`.

## Files

- `index.html` — the page content
- `style.css` — minimal styling
- `resume.pdf` — downloadable CV (linked from the page)
